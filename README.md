# ⚔️ JEE Battle Arena

Gamified JEE preparation app. Works offline as a PWA, ships as an Android APK via Capacitor.

---

## Prerequisites (local machine)

| Tool | Version | Install |
|------|---------|---------|
| Node.js | ≥ 18 | https://nodejs.org |
| JDK | 17 | https://adoptium.net |
| Android SDK | API 34 | Android Studio or SDK CLI tools |
| Git | any | https://git-scm.com |

Set SDK path (add to `~/.bashrc` or `~/.zshrc`):
```bash
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools
```

## First-time setup

```bash
# 1. Clone your repo
git clone https://github.com/<you>/jee-battle-arena.git
cd jee-battle-arena

# 2. Install Capacitor + dependencies
npm install

# 3. Add the Android platform (only needed ONCE)
npx cap add android

# 4. Copy web assets into android/ and sync plugins
npx cap sync android
```

## Build a debug APK (local)

```bash
./build-apk.sh
# APK → android/app/build/outputs/apk/debug/app-debug.apk
```

---

## Build a release APK (signed, for distribution)

### Step 1 — Generate keystore (one time only)
```bash
chmod +x gen-keystore.sh
./gen-keystore.sh
```

### Step 2 — Export signing env vars
```bash
export KEYSTORE_PATH=$(pwd)/jee-battle-arena.keystore
export KEY_ALIAS=jee-battle-arena
export KEY_PASSWORD=<your-key-password>
export STORE_PASSWORD=<your-store-password>
```

### Step 3 — Build
```bash
./build-apk.sh release
# APK → android/app/build/outputs/apk/release/app-release.apk
```

## Install on a device via ADB

```bash
# Debug
adb install -r android/app/build/outputs/apk/debug/app-debug.apk

# Release
adb install -r android/app/build/outputs/apk/release/app-release.apk
```

## Auto-build APK via GitHub Actions (CI/CD)

Every push to `main` automatically builds a debug APK:

```bash
git add .
git commit -m "feat: new boss mechanic"
git push origin main
# → GitHub Actions builds the APK
# → Download from: GitHub repo → Actions → latest run → Artifacts
```

### Enable signed release APKs in CI

Add these **GitHub Secrets** (Settings → Secrets → Actions):

| Secret | Value |
|--------|-------|
| `KEYSTORE_BASE64` | `base64 -w 0 jee-battle-arena.keystore` |
| `KEY_ALIAS` | `jee-battle-arena` |
| `KEY_PASSWORD` | your key password |
| `STORE_PASSWORD` | your store password |

## Day-to-day workflow

```bash
# Make changes to www/ (index.html, app.js, etc.)
# Then sync and rebuild:

npx cap sync android          # sync web → android
./build-apk.sh                # build debug APK
adb install -r android/app/build/outputs/apk/debug/app-debug.apk

# Or just push to git and let CI build it:
git add .
git commit -m "fix: leaderboard sync"
git push
```

## App IDs & config

Edit `capacitor.config.json` to change:
- `appId` — Android package name (e.g. `com.yourname.jeebattle`)
- `appName` — display name on device
- `webDir` — folder Capacitor reads (keep as `www`)

After changing config, always re-run `npx cap sync android`.

---

## Offline support

The service worker (`www/sw.js`) caches all assets on first load.  
The app runs fully offline after the first visit — this is preserved in the APK since Capacitor bundles all web assets locally.
